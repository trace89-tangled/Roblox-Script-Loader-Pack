## FAQ

### What is XCutors?

XCutors is a desktop application for Windows that bundles several popular Roblox script executors and a universal loader for easy management and script execution.

### Is XCutors free to use?

The XCutors loader and its management tools are free. However, some bundled executors (like Synapse Z) may require their own separate licenses.

### Does XCutors work on Mac or Linux?

No. XCutors is designed exclusively for Windows operating systems (Windows 10/11).

### Are there any anticomponent warnings when I run it?

Some anticomponent software may flag script execution tools as potentially unwanted. This is a common false positive for this type of software. You may need to add an exclusion.

### How do I update an individual executor?

Open the XCutors loader, select the executor you wish to update, and click the 'Check for Updates' button within its management panel.

### What should I do if an executor doesn't attach?

First, ensure Roblox is running and you've clicked 'Inject' in XCutors. If it fails, try running both Roblox and XCutors as Administrator, or check for executor updates.

### Can I suggest a new executor to be added?

Yes! Please open a new Issue on our GitHub repository and use the 'Suggestion' template to propose a new executor for inclusion.

### Is using script executors against Roblox's Terms of Service?

Yes. The use of third-party tools to execute scripts or modify game memory is generally prohibited by Roblox's Terms of Service. Use at your own risk.
